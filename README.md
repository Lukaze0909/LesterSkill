# release-method

一个基于莱斯特·莱文森（Lester Levenson）原始教导的 AI 释放法（圣多纳释放法 / Sedona Method）引导 Skill。让任何支持 Agent Skills 规范的 AI 助手，都能用莱斯特本人的语气和完整框架，带你做情绪释放。

不是简化版的"深呼吸放轻松"，是尽量贴近莱斯特原始录音/私教课/静修会内容整理出来的一整套方法：四步核心循环、三大想要(认同/控制/安全)、AGFLAP/CAP情绪量表、身体健康释放、关系释放、显化/金钱专题、自我探询等，源头材料来自莱斯特11份大部头教导原始转写 + Hale Dwoskin《Happiness Is Free》系列 + 92年释放法课程完整逐字稿。

## 快速开始

安装完成后，直接跟你的 AI 助手说：

```text
帮我释放一下，我今天因为一件事很焦虑，怎么都放不下
```

或者更具体地：

```text
释放法 我最近总是害怕失去很在乎的人，能带我走一遍吗
```

它会用莱斯特原始教导里的四步循环带你："聚焦此刻的感受 → 允许它待在这里 → 愿不愿意放下 → 什么时候" —— 不需要你先懂理论、先记步骤。

## 安装

```bash
npx -y skills add <github用户名>/<仓库名>
```

安装后回到你的 AI 助手，直接说"帮我释放"或"释放一下"即可触发。

支持任何遵循 [Agent Skills 开放规范](https://github.com/vercel-labs/skills) 的助手（Claude Code、Codex、Cursor、Trae、Qoder、Lingma 等，完整列表见该项目 README）。

## 这个 Skill 能做什么

| 场景 | 用法 |
| --- | --- |
| 当下有个具体情绪卡住，想放下 | 核心四步循环（聚焦-允许-放下-时间） |
| 表层情绪清完了，但感觉没到底 | 往三大想要（认同/控制/安全）继续深挖 |
| 说不清自己在纠结什么 | AGFLAP/CAP九级情绪量表 + 存在/行动/拥有三态模型 定位 |
| 身体疼痛、健康焦虑 | 身体疼痛具体处理法、身体认同极性释放 |
| 关系卡点、家庭冲突 | 关系释放技巧、喜欢/不喜欢清单、亲子引导 |
| 金钱/目标显化 | 显化练习、目标表格法 |
| 想往更深处走 | "我是谁"自我探询循环、丢弃倾向具体操作法 |
| 对死亡/彻底自由的恐惧 | 对死亡的恐惧专节，含莱斯特本人真实案例 |

## 源材料与引用原则

Skill 正文里凡是标注"莱斯特原话"的内容，都保留中英对照原文引用，不做转述改写——转述会加一层"别人嚼过的"中间层，违背这批材料最初想要公开分享的本意。

主要源材料：
- 莱斯特"莱斯特教导"11份大部头原始录音转写（方法、正确的道路、私教课、终极目标一/二卷、存在课程第一卷、莱斯特杂谈、炉边漫谈、静修会、100周年纪念、与莱斯特的谈话&视频3），来自中文翻译社群"穿腹子"整理并保持网盘永久分享的版本
- 92年原始圣多纳释放法课程完整8课逐字转写
- Hale Dwoskin《The Sedona Method》《Happiness Is Free》系列的方法论框架（书籍本身仍在售，Skill 中只摘录方法论要点和可直接引用的关键句，不包含书籍全文）
